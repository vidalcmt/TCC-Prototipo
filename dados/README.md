# Corpus

O corpus de validação é congelado em 25/10/2026 e não muda depois disso.
Cada resposta tem um código anônimo (por exemplo, R014) e uma origem
(autor, voluntario ou especialista). Nenhum nome de pessoa entra aqui.

Formato do arquivo de lote:

```csv
id,origem,nivel_pretendido,texto,veio_de_manuscrito,data_coleta
R001,autor,parcial,"texto da resposta...",nao,2026-10-18
```
